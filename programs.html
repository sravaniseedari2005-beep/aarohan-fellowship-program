04
PADERU 3 LEARNING BATCHES
Paderu, Andhra Pradesh

Paderu Online & Offline Batches

Paderu offers three learning tracks so students can explore different areas of technology. The first batch is offline and focuses on AI-enabled web designing, while the second and third batches provide focused pathways in Data Analytics and Machine Learning.

OFFLINE • BATCH 1

Web Designing (AI)

Learn modern web design and explore how AI can support creative and development workflows.

ONLINE • BATCH 2

Data Analytics

Understand data, analysis, visualisation and how data can support better decisions.

ONLINE • BATCH 3

Machine Learning

Build a foundation in machine learning concepts and explore practical AI applications.
